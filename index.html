TENTANG SAYA ABOUT ME

Seseorang dengan latar belakang Pendidikan Teknik Informatika yang fokus pada pengembangan media pembelajaran interaktif. Saya memiliki pengalaman dalam membangun game edukasi menggunakan Unity dan Construct 3, serta memahami alur kerja aset visual 2D maupun 3D.

Memiliki pengalaman praktis sebagai Asisten Laboratorium, di mana saya mengelola operasional teknis praktikum dan mendampingi rekan mahasiswa dalam pemecahan masalah sistematis.

Selain fokus pada pengembangan game, saya telah membekali diri dengan pemahaman fundamental di bidang Cloud Computing (AWS Academy) dan Cybersecurity (Cisco & TryHackMe) untuk mendukung kompetensi saya di infrastruktur IT.

Keahlian Teknis

A tech enthusiast with a background in Informatics Engineering Education, focusing on developing interactive learning media. I have experience in building educational games using Unity and Construct 3, along with a strong understanding of 2D and 3D visual asset workflows.
